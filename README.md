# Iris Classification using Logistic Regression

This project builds a machine learning model to classify iris flowers
into three species: *Iris-setosa*, *Iris-versicolor*, and *Iris-virginica*.

## Files
- `model.py` : Python script to train and predict using Logistic Regression.
- `iris_dataset.csv` : Dataset used for training and testing.
- `workflow.txt` : Notes on the project workflow.

## How to Run
1. Clone repo : git clone https://github.com/Ninad-18/ML-Iris-Flower
2. Install dependencies:
   ```bash
   pip install -r requirements.txt


RUN THE MODEL :
python model.py
